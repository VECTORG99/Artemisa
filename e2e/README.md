# Tests E2E

Pruebas end-to-end con Playwright.

## Requisitos

Backend y frontend en ejecucion. Ver README raiz para instrucciones.

## Ejecucion

```bash
npm test
npm run test:ui  # modo interactivo con UI
```

## Suites

- `tests/`: escenarios de integracion entre Creator y Runtime
- `fixtures/`: datos de prueba y mocks
