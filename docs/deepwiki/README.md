# DeepWiki Artemisa (espejo local)

Este directorio contiene una copia local de la documentación generada por DeepWiki para el repositorio `VECTORG99/Artemisa`.

- **Versión en inglés:** carpeta `en/` — contiene cada página extraída de DeepWiki en markdown.
- **Diagramas Mermaid:** carpeta `mermaid/` — cada diagrama se guarda en su propio archivo `.mmd` listo para renderizar.
- **`manifest.json`:** mapeo de título → archivo → diagramas.

La traducción al español de cada página está pendiente; por ahora el índice y los enlaces se mantienen en inglés.
